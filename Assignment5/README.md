# Assignment 5: Arrays: Traversal and Counting

## 1. Experiment Title

Arrays: Traversal and Counting in Java.

## 2. Aim

To write Java programs that traverse an array, find the sum and largest element, and count elements satisfying a condition.

## 3. Software / Tools Required

- Programming Language: Java
- JDK (Java Development Kit)
- IDE: IntelliJ IDEA / Eclipse / VS Code
- Any text editor (if IDE is not available)

## 4. Theory

The following concepts are used in this experiment:

1. **Array:** A collection of elements of the same data type stored in contiguous memory locations. Elements are accessed by index, starting from 0.
2. **Array Length:** `arr.length` gives the number of elements in the array.
3. **Traversal:** Visiting each element of the array one by one using a loop.
4. **Sum and Maximum:** A running total and a running largest value are updated while traversing.
5. **Counting:** A counter variable is increased whenever an element satisfies a condition.

## 5. Algorithm / Procedure

### Question 1: Array Traversal

1. Start the program.
2. Declare the array arr = {3, 4, 5}.
3. Run a for loop from index 0 to arr.length - 1.
4. Print each index with its value.
5. Stop the program.

### Question 2: Sum and Largest Element

1. Start the program.
2. Declare the array arr = {12, 45, 7, 33, 21}.
3. Initialize sum = 0 and largest = arr[0].
4. Traverse the array, adding each element to sum.
5. If an element is greater than largest, update largest.
6. Print sum and largest.
7. Stop the program.

### Question 3: Count Elements Greater than 10

1. Start the program.
2. Declare the array arr = {5, 12, 2, 14, 7} and count = 0.
3. Traverse the array.
4. If an element is greater than 10, increase count by 1.
5. Print count.
6. Stop the program.

## 6. Input

The following values are used in the experiment:

**Question 1:**

```
arr = {3, 4, 5}
```

**Question 2:**

```
arr = {12, 45, 7, 33, 21}
```

**Question 3:**

```
arr = {5, 12, 2, 14, 7}
```

## 7. Output

**Question 1:**

```
Index 0: 3
Index 1: 4
Index 2: 5
```

**Question 2:**

```
Sum: 118
Largest: 45
```

**Question 3:**

```
Count greater than 10: 2
```

**Result:** All three Java programs were successfully executed to demonstrate array traversal, summation, finding the maximum, and counting.
